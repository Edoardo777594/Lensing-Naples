# Lensing@Naples ResNet model
In this directory there are uploaded the 3 necessary file for make the model run.
1) Augment : the file where are deefined the function to read the files and also if you want some augmentation function
2) CNN_model : the file where the architecture of the model ([Li et al. 2021](https://ui.adsabs.harvard.edu/abs/2021ApJ...923...16L/abstract)) is defined 
3) Train : the file for the training of the model.
